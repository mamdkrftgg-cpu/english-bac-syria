# English Bac Syria Ultra

نسخة 2.0 من مشروع منصة تعليمية للبكالوريا العلمي السوري.

## ما الجديد
- تطبيق SPA فعلي: التنقل الداخلي لا يعتمد على صفحات HTML كثيرة.
- تصميم Mobile-first أقوى وأكثر اتساقاً.
- 12 وحدة وفق هيكل منهج 2026 المنشور على مصادر المنهاج.
- بنك مفردات موسع يتجاوز 1000 مدخل.
- نطق English عبر SpeechSynthesis.
- حفظ تقدم الطالب محلياً.
- XP / Hearts / Streak.
- مفضلة.
- درس تفاعلي.
- اختبار مفردات.
- امتحان تجريبي.
- Grammar Lab.
- Writing Coach.
- PWA + Service Worker للعمل بعد التخزين المؤقت.

## تشغيل
ارفع الملفات إلى GitHub Pages أو أي استضافة static. افتح index.html.

## دقة المحتوى
هيكل الوحدات مبني على منهج الثالث الثانوي العلمي السوري 2026. بنك الكلمات الإضافي موسع تعليميًا؛ لا يوصف بأنه تفريغ حرفي لكل كلمات الكتاب. لإنتاج نسخة مطابقة للكتاب والأنشطة صفحةً صفحة، يجب إدخال نسخة PDF الرسمية للطبعة المطلوبة ثم مراجعة الاستخراج يدوياً.
