# English Bac Syria — Pro

منصة Static تعمل مباشرة على GitHub Pages.

## المزايا
- بنك مفردات مع بحث وفلترة ومنع تكرار النتائج.
- نطق إنكليزي من المتصفح + ملفات صوتية لمختبر الاستماع.
- Listening Lab: مقطع كامل، كتابة من السماع، وتدقيق فعلي كلمة بكلمة.
- 12 وحدة، Grammar Lab، اختبار مفردات، أخطاء ومفضلة، وتقدم محلي.
- شريط تنقل سفلي ثابت وكبير ومناسب للموبايل.
- لون أساسي أخضر متوسط بدل البنفسجي.
- PWA + Service Worker.

## ملاحظة المحتوى
الملف المرفق «مفردات علمي 2022.pdf» عبارة عن صفحات مصوّرة؛ أداة استخراج الملفات لم تستطع قراءة نصه آليًا. لذلك لا يُسمح للمشروع بادعاء أن كل مدخل في البنك مأخوذ حرفيًا من كل صفحة من الملف. تم الاحتفاظ بالبنك الموجود سابقًا، وإضافة مجموعة مفردات مؤكدة من الصفحة الثانية التي أمكن فحصها بصريًا. يلزم OCR/مراجعة صفحة-بصفحة لإثبات التطابق الكامل مع الـPDF.
